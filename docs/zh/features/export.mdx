## 格式

| 格式 | 说明 |
|------|------|
| PPTX | 幻灯片以图片形式嵌入 PPT，可在 PowerPoint 中播放和调整页面顺序，但图片内的文字无法直接编辑 |
| 可编辑 PPTX（Beta） | 从图片中提取文字重建为原生文本框，可在 PowerPoint 中直接编辑文字内容 |
| 原生可编辑 PPTX | 原生可编辑项目直接把 HTML 页面逐元素写入 PPTX，不依赖 MinerU、背景修复或图片识别服务 |
| PDF | 像素级精确输出，可直接演示 |
| 图片 | 每页导出为独立图片文件 |
| 讲解视频 | 将幻灯片图片与 AI 旁白合成为 MP4 视频，可选字幕与画面动效 |

<Note>
  Docker 部署已在镜像内安装好视频导出所需的 FFmpeg 依赖。源码部署请先安装带 `libass` / `ass` 字幕滤镜的 FFmpeg，例如 macOS 运行 `brew install ffmpeg-full && brew unlink ffmpeg 2>/dev/null || true && brew link --overwrite --force ffmpeg-full`，Ubuntu / Debian 运行 `sudo apt-get update && sudo apt-get install -y ffmpeg libass9`。
</Note>

## PPTX 导出面板

普通 PPTX 导出会先弹出设置面板，再开始生成文件。可开启「页面切换动画」，并选择淡入淡出、翻页、平移切换、擦除、分割、百叶窗、棋盘、时钟等经典效果；如果同时选择多个效果，导出时会为每页随机使用其中一种。

## 已导出文件

幻灯片预览页的导出任务面板会列出当前项目已经保存在服务器上的导出文件。你可以在这里重新下载 PPTX、PDF、图片压缩包或讲解视频，也可以删除不再需要的文件以释放磁盘空间。删除前会弹出确认提示；删除后文件会从服务器存储和面板列表中移除。

导出任务的历史记录按项目隔离显示；在某个项目中点击「清除」只会清除当前项目的已完成或失败任务，不会影响其他项目的导出历史。

## 讲解视频旁白策略

讲解视频导出会在最后一步弹出单独的配置面板，可在真正开始导出前调整旁白生成策略，而不影响页面内容本身。

- 可配置演讲者人设、目标受众、演讲基调、核心主题
- 可配置单页旁白字数范围，适配快节奏短视频或更完整的深度讲解
- 缺失旁白时可选择由系统自动生成，生成结果会按整套演示文稿保持前后衔接
- 可在免费的 Edge TTS 与 Fish Audio `s2.1-pro-free` 之间选择；Fish Audio 支持私有语音克隆、2–4 人原生多人旁白和按页面场景自动匹配语气

Fish Audio 的 Key 配置、声音克隆、多人协议和使用限制见 [Fish Audio 旁白与语音克隆](/zh/features/fish-audio)。

## 可控视频文案

讲解视频默认使用文案工作台中已经确认的当前版本，不会在点击导出后静默改写。

- 可以逐页直接编辑文案，并保存为新的人工版本
- AI 润色只生成候选稿；预览差异并应用后，才会成为当前稿
- 可以查看历史版本并恢复；恢复操作会创建新版本，不覆盖旧记录
- 锁定的页面默认跳过批量生成和批量润色
- 导出启动时会冻结文案版本、角色、语言、音色、TTS 参数和时间轴；之后继续编辑不会改变已启动任务

双人或多人模式下，每段文案都绑定明确的角色。Edge TTS 按段合成，Fish Audio 使用一次页面级多人请求保持对话上下文。语气首先保存为与供应商无关的语义信息，再在合成阶段转换为对应引擎支持的参数。

## 视频画面动画

桌面生产包默认启用 Hyperframes 动画渲染。源码或服务端部署需要同时设置：

```bash
EASYSLIDE_HYPERFRAMES_ENABLED=true
EASYSLIDE_IMAGE_SCENE_ENABLED=true
```

- **原生编辑模式**：直接动画标题、正文、图片、数字和图表等真实结构化元素，不先把整页截图扁平化
- **新图片模式**：背景由图片模型生成，标题、正文和结构化图表分别以 HTML/SVG 图层渲染；预览 hero frame 与视频来自同一 Scene
- **历史图片模式**：在图片历史版本菜单中点击「恢复动画图层」，系统异步识别区域、修复背景并重建可动画 Scene
- 旁白段落显式指定焦点元素时优先使用指定结果；未指定时按文案关键词自动匹配对应标题、正文或图表

历史图片恢复分级如下：

| 级别 | 实际效果 |
|------|----------|
| L0 | 完整背景与高置信元素分层动画 |
| L1 | 可靠文字或重点元素分层动画 |
| L2 | 仅区域聚焦或遮罩揭示 |
| L3 | 增强 Ken Burns、平移与淡入 |
| L4 | 静态页面与转场 |

只有通过 hero 视觉差异和图层质量门禁的 L0/L1 Scene 才会进入最终视频。低质量恢复不会阻止允许降级的导出，而是自动使用 L2-L4，并在预检、图片版本详情和任务质量报告中显示具体页面、级别、原因及实际渲染器。

## 视频导出失败与降级

- TTS 网络失败会按引擎策略重试；关闭「允许返回半成品」时，仍有页面无法生成有效语音则停止导出
- 开启「允许返回半成品」后，失败页面可以静音继续，但不会未经授权把 Fish 私有声音替换为 Edge 音色
- Hyperframes 失败时依次回退到浏览器帧序列和 Ken Burns/静态镜头；旁白、字幕和时间轴工件不会重复生成
- 导出任务保留 Audio Timeline、Motion Manifest、Scene 引用、渲染快照和逐页降级原因，便于复现失败

## 画面比例

默认 16:9，也可在创建项目时或项目预览页的「项目设置」中更改。支持 16:9、4:3、21:9、1:1、9:16 等多种比例。比例变更后需重新生成图片才会生效。

## 可编辑 PPTX（Beta）

提取过程保留字号、颜色、加粗样式、文字定位和表格内容，但受限于 OCR 精度和当前模型能力，复杂排版可能存在偏差，与原图效果有出入。

<Note>
  配置 `BAIDU_API_KEY` 可获得最佳提取效果，详见[配置说明](/zh/configuration#百度-api-key)。
</Note>

## 原生可编辑导出

新建项目时选择「原生可编辑」，页面以受控布局和结构化内容保存。文字、基础形状和图片从真实 HTML 逐元素导出，复杂视觉才使用局部图片回退；系统禁止整页截图与同页可编辑文字重叠。

原生 PPTX 在浏览器或桌面应用内生成，不访问 MinerU、背景修复或图片识别模型。导出任务可在页面边界暂停；应用退出后任务显示为已暂停，继续时从已保存的页面结构重新生成。完成后可查看逐页文字、形状、图片和警告数量的质量报告。

## 选页导出

可选择特定页面导出，无需导出整个演示文稿。在幻灯片预览页开启「多选」，勾选要导出的页面后点击「导出」即可。

导出菜单会按本次选择范围检查图片状态：PPTX、PDF、图片和可编辑 PPTX 需要选中范围内每一页都已生成图片；未选中的草稿页不会阻止已完成页面导出。讲解视频如果范围内还有未配图页面，需要在视频导出面板中明确勾选「包含未配图页面」后，才会用占位帧继续导出。

## 允许返回半成品

「项目设置 → 导出设置」里的「允许返回半成品」会统一作用于导出链路。

- 关闭时：只要导出过程中出现关键缺失或失败，例如可编辑 PPTX 提取失败、视频导出缺少旁白文本或无法合成有效语音，任务会立即失败，不再返回不完整结果。
- 开启时：系统会尽量继续导出。例如视频导出在个别页面没有可用旁白时，会回退为静音片段继续生成最终 MP4。
