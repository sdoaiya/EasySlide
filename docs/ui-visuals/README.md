## 视觉方向

- 保留 Apple 式低噪声、稳定三栏和即时反馈。
- 恢复 EasySlide 原本更丰富的蓝、青、珊瑚、琥珀、紫、海蓝色彩。
- 工作区保持克制，创建页、项目中心、主题预览和任务状态允许更鲜明。
