# 原生页面版本与工作区交互设计

## 目标

原生可编辑页面重新生成后保留旧版本，项目关闭后仍可切换；同时修复导出任务定位、演示全屏和页面意图文案。

## 方案

- 每个页面新增 `native_versions` JSON 字段，只保存历史快照，不复制当前版本。
- 生成任务覆盖已有原生页面前写入 `{id, layout, props, created_at}` 快照；首次生成不写快照。
- 版本接口读取历史快照加当前页面，切换历史版本时先把当前内容保存为快照，再将选择的快照设为当前，保证不会丢失任何版本。
- 原生工作区在页面属性中提供“重新生成本页”和版本菜单；重新生成仍复用现有定向页面生成任务。
- 导出任务面板挂在任务按钮下方；演示使用应用内覆盖层，不请求浏览器全屏权限。

## 验收

1. 原生页重新生成后可切换生成前后版本，重新打开项目仍可切换。
2. 成功页和回退页均可单页重新生成。
3. 演示覆盖应用窗口，且可退出。
4. 导出任务面板与任务按钮对齐，页面意图改为页面摘要并隐藏 Dashi 标识。
