# EasySlide Apple 风格 UI 重构计划 v2

> 2026-07-26 补充：本文件保留为早期问题清单；视觉取向以 `docs/UI_RULES.md` 和 `docs/superpowers/specs/2026-07-26-editorial-workbench-ui-baseline.md` 为准。旧文中的系统蓝主按钮、顶部导航和 PPT 单一项目卡片描述已被“墨黑主操作、单一 216px 工具架、内容项目作品墙”覆盖。

## 目标

基于当前代码和现有 `docs/UI_RULES.md`，完成一次可验收的 UI 收口：统一首页、创建流程、图片模式和原生可编辑模式的视觉语言与操作路径，修复当前已经暴露的布局断层。业务 API、项目数据结构、生成和导出核心协议保持不变；本计划不重新引入已移除的 ElevenLabs 配置。

## UI 技能约束

- 所有 UI 设计、实现和 review 必须先使用 `apple-design`：即时 pointer-down 反馈、可中断且从当前状态继续的动效、稳定空间锚点、克制材质和 reduced-motion。
- 所有 UI 设计、实现和 review 同时使用 `ui-ux-pro-max`：信息架构、响应式断点、可访问性、图表交互、错误恢复、触控尺寸和交付前 UX 检查。
- 两项技能与 `docs/UI_RULES.md` 共同构成唯一 UI 规则；不在业务页面另建颜色、按钮、弹窗或动效体系。

## 当前问题基线

1. 首页路由/入口直接落到创建项目，项目中心的导航、最近项目和空状态没有成为真正的首页。
2. 图片画布工具栏存在重复入口，页面内按钮、浮动按钮和任务入口的职责重叠。
3. 原生可编辑画布可以导出讲解视频，但没有对应的视频参数面板，用户只能直接启动任务。
4. 导出任务状态图表/详情在右侧面板内打开时定位偏移，存在被裁切或出现在错误坐标系的问题。
5. 全局 Apple token 已部分接入，但仍有页面沿用旧背景、旧色值和局部卡片样式，整体看起来单调且未完成。
6. 预设模板与系统预设模板存在重复概念；前端当前有一组 8 个预设卡片，后端系统模板接口尚未实现。
7. 原生主题预览和部分背景仍未完全切换到统一的暖灰工作区和真实主题预览规则。

## 不可破坏规则

- 图片模式与原生模式共用工作区壳层、任务中心、设置入口和导出体验。
- 中央画布宽度只由工作区网格决定，右侧属性内容永远不能撑动或压缩画布。
- 进入生成页面不自动批量生成；只有用户点击批量生成后才开始，已上传/已生成图片不覆盖。
- 长任务必须进入任务中心，支持进度、暂停、继续、失败原因、重试、下载和质量报告。
- 输入控件只保留一种焦点反馈，不叠加 outline、border、shadow 多重高亮。
- 统一使用语义 token；新增 UI 不直接使用 cyan、sky、slate 或旧 banana 色值。
- 桌面优先，`1280x720`、`1440x900`、`1920x1080` 和 Windows 125% 缩放均需可用。

## 执行顺序

### P0：先修信息架构和明显断层

#### 1. 首页与创建页分离

- 恢复项目中心为默认首页：最近项目、进行中任务、创建项目主入口和空状态均在首页展示。
- 创建项目只通过导航“创建项目”、首页主按钮或项目列表空状态进入。
- 统一为单一 `216px` 左侧工具架：首页、创建项目、我的项目、图片素材、素材生成、设置；进入项目后复用同一外壳承载工作区和内容索引。
- 项目重新打开时按项目保存的阶段恢复到大纲、详情、图片生成或原生编辑页，不再统一落到创建页。
- 验收：刷新根路由进入项目中心；点击创建后才进入创建流程；已有项目可返回上次页面。

#### 2. 工作区工具栏收口

- 以 `WorkspaceShell` 为唯一工作区外壳，图片模式和原生模式只提供一组顶部操作。
- 按职责分组：页面导航、视图缩放、生成/批量生成、任务、导出、更多设置。
- 删除同一动作的重复按钮；导出只保留一个主入口，任务中心只保留一个入口。
- 画布底部只保留缩放和视图辅助操作，不能再次复制顶部导出/生成按钮。
- 验收：同一动作在一个视口只出现一次；1280px 下按钮不换行、不遮挡画布。

### P1：导出视频和任务中心

#### 3. 原生模式视频配置前置

- 原生可编辑画布点击“导出讲解视频”先打开统一视频设置 Sheet，再创建任务。
- 设置项与图片模式保持同一套：旁白文本策略、edge-tts 音色、语速、字幕、镜头动效、视频风格、页面范围、半成品策略。
- 参数通过现有 `director_config` 和导出请求传递，不新增另一套视频协议。
- 设置 Sheet 的标题、底部操作和滚动区域固定；点击取消不创建任务，确认后才进入任务中心。
- 历史任务可查看实际使用的配置摘要；不显示已删除的 ElevenLabs 选项。

#### 4. 修复任务图表定位

- 任务详情/质量报告使用固定于视口的 Popover/Sheet 定位，不以右侧滚动容器作为坐标系。
- 打开时使用触发按钮的 `getBoundingClientRect()` 计算锚点；滚动、窗口缩放和侧栏切换时重新定位。
- 当锚点附近空间不足时自动翻转到上方或改为全高 Sheet，禁止被 `overflow: hidden` 裁切。
- 任务列表和详情层级统一，关闭支持 Escape、遮罩和明确关闭按钮。
- 验收：在右侧栏滚动、任务面板滚动、1280/1440/1920 宽度下点击同一任务，详情始终贴近触发项且不越界。

### P2：模板与主题数据源统一

#### 5. 预设模板合并

- 取消“预设模板”和“系统预设模板”的重复展示概念。
- 前端当前 8 个预设卡片直接改为系统预设模板列表；保留上传模板卡片作为第一项。
- `TemplateSelector` 只消费一个 `systemTemplates` 数据源，统一 id、名称、缩略图、说明、适用模式和主题色。
- 后端 `/api/templates` 完成系统预设模板读取；若系统模板由静态资源提供，前后端统一静态 manifest，避免两套硬编码。
- 图片模式显示系统模板；原生模式隐藏不适用的图片模板，只显示 12 个原生主题和文字风格微调。
- 验收：创建页不再出现两个预设区；8 个卡片全部来自系统模板数据；刷新后选择状态稳定。

#### 6. 主题预览真实化

- 12 个原生主题使用真实渲染缩略图或高质量静态截图，不再使用粗糙占位图。
- 预览同时呈现背景、标题层级、正文、强调色、图片占位和图表/装饰倾向，用户能看出主题差异。
- 主题切换只改变主题 token、布局约束和视觉参数，不重写当前页面内容；切换失败保留旧主题并显示局部错误。
- 主题预览卡片和工作区画布共用同一套主题 token，避免“预览一种颜色、实际生成另一种颜色”。

### P3：视觉系统收口

#### 7. 背景和色彩完成度

- 逐页审计 `index.css`、`WorkspaceShell`、首页、创建页、设置页、素材中心、任务中心和两种编辑器的直接颜色。
- 统一层级：应用背景 `#F5F5F7`、工作区雾灰画布 `#EDEEF0`、主表面白色、次表面浅灰、分隔线、墨黑主操作、系统蓝焦点/链接和成功/警告/错误状态色。
- 通过 `surface / material / sidebar / canvas / separator / accent / status / shadow / radius / motion` 语义 token 表达，不把整页做成单一灰白色。
- 色彩变化来自表面层级、主题预览和状态色，不使用大面积渐变、光晕、彩色滚动条或装饰性彩色卡片。
- 深色主题只用于主题预览和必要的内容画布，不把业务外壳重新做成深蓝或紫色渐变。
- 验收：截图中应用背景、画布、面板和主操作有清晰层次；不存在旧 banana/青蓝渐变按钮和未迁移的大块旧背景。

#### 8. 共享控件一致性

- 完成 `Button`、`Card`、`Input`、`Textarea`、`Modal`、`Toast`、分段控件、任务面板和项目设置的 token 化。
- 主按钮为墨黑实色，次按钮为白色/中性表面描边，系统蓝只用于焦点、链接和强选择；低优先级操作使用图标按钮，并提供 pointer-down、loading、disabled、tooltip 和键盘焦点。
- 长文本字段固定高度并内部滚动；需要查看全文时使用展开 Sheet，不改变主布局高度。
- 通知按规则自动关闭；长任务不依赖 Toast，统一进入任务中心。

### P4：性能、响应式和无障碍验收

- 原生缩略图继续按视口懒渲染；隐藏导出画布只在真正导出时挂载。
- 属性修改局部更新，避免重绘整个工作区；任务进度更新不触发编辑器布局重排。
- 侧栏在 1280px 以下改为覆盖式抽屉，中央画布尺寸保持不变；桌面标题栏和页面导航不产生横向溢出。
- 所有 Sheet/Popover 支持 Escape、焦点回收、`aria-live` 状态、键盘导航和 reduced-motion/reduced-transparency。

## 文件级实施边界

- 路由与首页：`frontend/src/App.tsx`、`frontend/src/pages/Home.tsx`、`frontend/src/pages/History.tsx`、`frontend/src/components/history/ProjectCard.tsx`。
- 工作区：`WorkspaceShell.tsx`、`NativeDeckWorkspace.tsx`、`NativeDeckCanvas.tsx`、`SlidePreview.tsx`、`ExportTasksPanel.tsx`。
- 模板与主题：`TemplateSelector.tsx`、`NativeThemePicker.tsx`、`presetStyles.ts`、系统模板 controller/manifest 及对应测试。
- 视频导出：现有视频设置组件、`SlidePreview`/原生工作区导出入口和 `export_controller.py` 的既有 `director_config` 请求链路。
- 样式底座：`frontend/src/index.css` 及共享 `Button/Card/Input/Textarea/Modal/Toast`，不新增第二套设计系统。

## 验收与交付门槛

### 自动化

- 现有前端单元测试全部通过。
- 新增/更新测试覆盖：首页默认路由、创建页入口、模板单列表、原生/图片模式工具栏去重、视频设置确认/取消、任务详情定位、工作区三栏不互相撑动。
- Playwright 覆盖 `1280x720`、`1440x900`、`1920x1080`、移动窄屏和 reduced-motion；截图检查无白屏、无重叠、无横向溢出。
- 生产构建、桌面打包和产物启动验证通过；导出视频、可编辑 PPTX 和图片模式导出请求行为不回归。

### 人工验收路径

1. 从首页进入创建项目，选择图片模式和原生模式，确认模板/主题控件只显示适用内容。
2. 进入图片画布和原生画布，确认工具栏无重复动作，中央画布居中且不受右栏内容影响。
3. 在原生模式点击导出讲解视频，确认先出现设置面板，取消不创建任务，确认后任务进入统一任务中心。
4. 在任务中心点击进度图表和质量报告，滚动右栏后再次点击，确认详情定位正确且不被裁切。
5. 切换主题、修改属性、生成图片和导出，确认局部状态反馈、无白屏、无重影、无自动覆盖已有素材。

## 后续功能接入规则

任何新功能必须先判断属于首页、创建流程、工作区、属性栏、任务中心或设置中的哪一层，优先复用现有语义 token、共享组件和任务协议；不得在业务页面单独引入一套颜色、按钮、弹窗或布局。提交前必须补充对应的响应式、键盘和 reduced-motion 验证。
