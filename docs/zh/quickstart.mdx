## 自托管部署

### 第一步：安装 Docker

<Tabs>
  <Tab title="Windows / macOS">
    下载并安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)，安装完成后启动它，确保系统托盘（Windows）或菜单栏（macOS）中出现 Docker 图标。
  </Tab>
  <Tab title="Linux">
    ```bash
    curl -fsSL https://get.docker.com | sh
    ```
  </Tab>
</Tabs>

### 第二步：一键下载并启动

在 EasySlide 项目根目录执行以下命令，复制环境变量示例文件：

```bash
cp .env.example .env
```

然后编辑 `.env` 文件，填入你的 API 密钥（详见[配置说明](/zh/configuration)），再启动：

```bash
docker compose -f docker-compose.prod.yml up -d
```

<Tip>
  使用 OpenAI 模式时，请在 [OpenAI Platform](https://platform.openai.com/api-keys) 创建 API Key，然后粘贴到设置页。
</Tip>

### 第三步：访问应用

浏览器打开 [http://localhost:3011](http://localhost:3011)，即可开始使用。

<Note>
  默认端口为 3011（前端）和 5011（后端）。如需修改，在 `.env` 中设置 `FRONTEND_PORT` 和 `BACKEND_PORT`。
</Note>

## 更新

在应用内进入 **设置 → 关于 → 检查更新**，可以根据当前版本 SHA 判断是否已有可用更新；源码运行时也会用当前 Git SHA 参与判断。

```bash
docker compose -f docker-compose.prod.yml pull && \
docker compose -f docker-compose.prod.yml up -d
```

## 查看日志

```bash
docker logs -f --tail 100 easyslide-backend
```

## 从源码部署

<Accordion title="展开查看源码部署步骤">

### 环境要求

- Python 3.10+
- [uv](https://github.com/astral-sh/uv) 包管理器
- Node.js 16+ 和 npm

### 后端

```bash
cd easyslide
cp .env.example .env  # 编辑 .env 填入 API 密钥
cd backend
uv run alembic upgrade head && uv run python app.py
```

### 前端

```bash
cd frontend
npm install
npm run dev
```

</Accordion>
